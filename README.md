# hnsc-radiomics-ml
# Прогнозирование 5-летней выживаемости при HNSCC на основе радиомики

## 🎯 О проекте
Цель данного проекта — построить модель машинного обучения для предсказания пятилетней выживаемости пациентов с плоскоклеточным раком головы и шеи (HNSCC) на основе текстурного (радиомического) анализа опухоли и клинических данных.

**Задача:** Бинарная классификация (выжил / не выжил в течение 5 лет).

## 📊 Данные
- **Источник:** Датасет HNSCC с платформы [radiomics.uk](https://radiomics.uk/).
- **Исходные признаки:** 105 радиомических признаков (shape, firstorder, GLCM, GLDM, GLSZM, NGTDM), извлеченных из КТ-снимков.
- **Клинические данные:** Возраст, пол, статус курения, ИМТ.
- **Объем выборки:** 125 пациентов.

## 🛠 Что было сделано в ходе работы:
1. **Предобработка и объединение данных:**
   - Объединение текстурных признаков (features) с клиническими данными (clinical data).
   - Кодирование категориальных признаков (пол) через `OneHotEncoder`.
2. **Отбор признаков (Feature Selection):**
   - Использован алгоритм **mRMR** (Minimum Redundancy Maximum Relevance) для отбора 10 наиболее релевантных признаков (использованы критерии KS и RF).
   - Проведен корреляционный анализ Спирмена для устранения мультиколлинеарности (отброшены признаки с корреляцией > 0.7).
3. **Построение модели:**
   - Разделение данных на Train/Test с сохранением стратификации (80/20).
   - Обучен классификатор **Extra Trees** с настройкой гиперпараметров (`n_estimators`, `max_depth`, `min_samples_split`).
4. **Оценка качества:**
   - Построена матрица ошибок (Confusion Matrix).
   - Рассчитаны метрики: ROC-AUC, F1-score, Sensitivity (Recall), Specificity, Precision (PPV), NPV.
   - Построена ROC-кривая.

## 💡 Результаты
- **ROC-AUC (Test):** 0.641
- **F1-score (Test):** 0.640
- Модель показала сбалансированные результаты по чувствительности (0.66) и специфичности (0.61), что говорит о способности улавливать закономерности, однако для клинического применения требует дальнейшей валидации на больших данных.
